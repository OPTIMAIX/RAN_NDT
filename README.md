# RAN_NDT
Functions of the RAN NDT

This includes the following functions:
- prop_model: computation of path loss for different types of propagation models
- LOS_prob: Computation of the LOS probability for different propagation models
- mobility_model_cars: Computes the position update for a car that moves through the scenario following the streets
- mobility_model_pedestrian: Computes the position update for a pedestrian that moves through the scenario, either following the sidewalks of the streets or the open areas.
